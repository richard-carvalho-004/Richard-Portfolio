A single-page static portfolio with no build step and no dependencies: one `index.html` with inline CSS and JavaScript.

## Features

- Typewriter hero that cycles through roles
- Skills panel grouped by CI/CD, cloud, monitoring and scripting
- About, experience and project sections, with project details in modals
- Downloadable resume
- Responsive layout for desktop, tablet and mobile
- Respects `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser.

## Deploy

GitHub Pages serves the `main` branch root. Every push to `main` redeploys the site.
